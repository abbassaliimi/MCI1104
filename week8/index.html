Topic 01 Estimated Time: 30 Mins

Introduction to Regression & Linear Modeling

Introduction: Up until now, you have explored how to clean, represent, and structure data. Now we transition into Predictive Analytics. While classification answers "Which category?", regression answers "How much?" or "How many?". In this module, you will learn how to model continuous numerical targets using the foundational workhorse of predictive modeling: Simple Linear Regression.

Core Concept: Regression analysis estimates the mathematical relationship between variables. Simple Linear Regression models the relationship between a single independent variable ($X$) and a single continuous dependent target variable ($Y$) using a straight line.

The Linear Equation

$$y = \beta_0 + \beta_1 x + \epsilon$$

  • $y$: Continuous dependent variable (e.g., house price or salary).
  • $x$: Single independent predictor variable (e.g., house size in sq ft).
  • $\beta_0$: Y-intercept (predicted value of $y$ when $x = 0$).
  • $\beta_1$: Slope coefficient (change in $y$ per 1-unit increase in $x$).
  • $\epsilon$: Random error term or residual.

Topic 02 Estimated Time: 35 Mins

Ordinary Least Squares (OLS) & Line of Best Fit

Core Concept: There are infinitely many straight lines you could draw through a scatter plot of data points. Ordinary Least Squares (OLS) is the mathematical optimization method used to find the unique "line of best fit".

Residual ($\epsilon_i$): Vertical distance between observed ($y_i$) and predicted ($\hat{y}_i$) value:

$$\text{Residual} = y_i - \hat{y}_i$$

The OLS Objective: Minimizes the Sum of Squared Residuals (SSR) across all $N$ data points:

$$\text{Minimize } SSR = \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

Why Square the Errors?
  • Prevents positive and negative residuals from canceling each other out.
  • Heavily penalizes larger prediction errors, pulling the line closer to distant data points.

Topic 03 Estimated Time: 30 Mins

Evaluating Regression Performance

Core Concept: Once OLS draws the line of best fit, you need quantitative metrics to measure how well that line actually captures the variation in your dataset.

3 Key Performance Metrics Evaluation
1. Coefficient of Determination ($R^2$)

Proportion of variance in $Y$ explained by $X$ ($0.0 \le R^2 \le 1.0$).

2. Mean Absolute Error (MAE)

Average absolute error in target units (e.g., off by an average of $15,000).

3. Root Mean Squared Error (RMSE)

Square root of average squared errors; penalizes large outliers severely.

Core Assumptions of Linear Regression

Core Concept: OLS produces unbiased predictions only when specific theoretical assumptions are satisfied. Violating these assumptions can lead to unreliable coefficients or invalid conclusions.

  • 1. Linearity: Underlying relationship between $X$ and $Y$ must be linear.
  • 2. Independence: Observations must be independent (no correlation among residuals).
  • 3. Homoscedasticity: Residual variance remains constant across all levels of $X$.
  • 4. Normality of Residuals: Prediction errors follow a normal distribution centered at zero.

Conceptual Bridge

Moving Beyond a Single Predictor

Simple Linear Regression provides a strong foundation for modeling continuous targets using a single feature.

However, real-world outcomes are rarely driven by one factor alone (e.g., house prices depend on square footage, location, age, and bedrooms). Next week, in Multiple Regression, we expand our model to evaluate multiple independent variables simultaneously.

Simple vs. Multiple Regression Transition

This Week (Week 8) Simple Linear Regression

Single independent predictor ($X$) predicting a single dependent target ($Y$):

$$y = \beta_0 + \beta_1 x + \epsilon$$

Next Step Multiple Linear Regression

Multiple independent predictors ($x_1, x_2, \dots, x_p$) evaluating complex real-world target drivers:

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \epsilon$$
