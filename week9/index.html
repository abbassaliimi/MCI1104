Extending Simple to Multiple Regression

Core Concept: Simple Linear Regression uses 1 feature to predict a target in 2D space. Real-world systems depend on multiple predictors simultaneously ($x_1, x_2, \dots, x_p$). Moving into multi-dimensional space fits a hyperplane through the data.

1 Predictor ($p=1$) 2D Regression Line
2 Predictors ($p=2$) 3D Fitting Plane
$p \ge 3$ Predictors High-D Hyperplane
Interactive Reflection:

If modeling home price ($y$) using square footage ($x_1$) and number of bedrooms ($x_2$), why might the coefficient for bedrooms ($\beta_2$) turn negative when holding square footage constant?

💡 Answer: Holding total square footage constant while adding more bedrooms forces individual rooms to become smaller! Buyers often prefer spacious layouts over cramped rooms for the exact same total square area.

Topic 02 Estimated Time: 25 Mins

Mathematical Formulation

The Multiple Regression Model Equation:
$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p + \epsilon$$
$\beta_0$ (Intercept): Expected mean value of target $y$ when all predictor features $x_1, \dots, x_p$ equal zero.
$\beta_j$ (Partial Regression Coefficients): Estimated change in $y$ per unit increase in $x_j$, holding all other independent variables strictly constant (Ceteris Paribus).
$\epsilon$ (Residual Error): Random noise component $\epsilon \sim \mathcal{N}(0, \sigma^2)$.

Matrix Formulation & Partial Slope Simulator

Compact Matrix Representation
$$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\epsilon}$$
OLS Closed-Form Solution: $\hat{\boldsymbol{\beta}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$

Topic 03 Estimated Time: 25 Mins

OLS Gauss-Markov Assumptions

For Ordinary Least Squares (OLS) to be the BLUE (Best Linear Unbiased Estimator), 5 core Gauss-Markov mathematical conditions must be satisfied.

The 5 Pillar Assumptions

  1. 1
    Straight-Line Trend (Linearity)

    Each input feature impacts the target outcome in a steady, proportional way.

  2. 2
    Unbiased Predictions (Zero Mean Error)

    Prediction mistakes cancel out to zero on average without systematically over- or under-estimating.

  3. 3
    Consistent Mistake Size (Homoscedasticity)

    The spread of prediction errors stays roughly equal across low, medium, and high values.

  4. 4
    Independent Mistakes (No Autocorrelation)

    Making a mistake on one data point tells you nothing about the error on the next data point.

  5. 5
    Unique Features (No Multicollinearity)

    Input variables don't duplicate identical information, allowing the model to isolate each variable's true impact.

Topic 04 Estimated Time: 35 Mins

Understanding Multicollinearity

Core Concept: Multicollinearity occurs when independent variables ($x_1, x_2$) share near-identical information (e.g. House Size in SqFt vs House Size in SqMeters).

⚠️ Mathematical Consequences:
  • Matrix Singular Instability: $(\mathbf{X}^T \mathbf{X})^{-1}$ becomes near-singular and hard to invert.
  • Inflated Standard Errors: Confidence intervals expand, destroying statistical significance ($p$-values rise falsely).
  • Erratic Coefficients: Small data changes flip signs of $\beta$ back and forth.

Variance Inflation Factor (VIF)

VIF Mathematical Formula:
$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$

Where $R_j^2$ is the coefficient of determination obtained by regressing predictor $x_j$ against all other independent variables.

VIF Rule-of-Thumb Thresholds:
VIF = 1 No Correlation
1 < VIF < 5 Moderate (OK)
VIF ≥ 5 - 10 Severe Collinearity

Topic 06 Estimated Time: 30 Mins

Model Evaluation & Adjusted $R^2$

Standard $R^2$ (Flawed)

Measures variance explained. Flaw: Always stays equal or increases when any variable is added, even random noise!

Adjusted $R^2$ (Corrected)

Measures true quality. Fix: Penalizes the model for adding useless features that do not improve predictions.

Adjusted $R^2$ ($\bar{R}^2$) Formula Complexity Penalty Model
$$\bar{R}^2 = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - p - 1} \right]$$
$R^2$ Raw Score
$n$ Sample Size
$p$ # of Predictors

💡 How the Penalty Works: As you increase $p$ (add features), the denominator $(n - p - 1)$ gets smaller, making the penalty fraction larger. If the new feature doesn't boost $R^2$ enough to overcome this penalty, $\bar{R}^2$ decreases!

Feature Overfitting Divergence Curve

Penalty Threshold Demo
Practical Model Selection Rule:

When comparing candidate models, always pick the model with the highest Adjusted $R^2$. If adding a new feature causes Adjusted $R^2$ to fall, discard that feature—it is diluting model quality with noise.

Topic 07 Estimated Time: 25 Mins

Feature Selection & Parsimony

Principle of Parsimony: Prefer simpler models with fewer features. They prevent overfitting, enhance interpretability, and reduce deployment costs.

Forward Selection:

Starts with 0 features $\rightarrow$ Iteratively adds variable with lowest $p$-value until no addition improves model.

Backward Elimination:

Starts with ALL features $\rightarrow$ Iteratively drops least significant variable ($p > 0.05$) one by one.

Backward Elimination Execution Flowchart

1
Fit Full Model:

Include all candidate predictors ($x_1, x_2, \dots, x_p$).

2
Check Highest $p$-value:

Find feature with largest $p$-value. Is $p > \alpha_{\text{stay}} = 0.05$?

3
Remove & Re-fit:

If YES $\rightarrow$ Drop feature and re-estimate model. Repeat Step 2.

4
Stop & Finalize:

If NO (all $p \le 0.05$) $\rightarrow$ Model optimization complete!

Categorical Variables & The Dummy Trap

Regression equations require numeric inputs. Qualitative categories (e.g. Location: Urban, Suburban, Rural) must be converted into 0/1 binary Dummy Variables.

⚠️ The Dummy Variable Trap ($k - 1$ Rule):

If a categorical variable has $k$ levels, you MUST include only $k - 1$ dummy columns! Including all $k$ columns creates perfect multicollinearity because the sum of all dummy columns equals 1 (matching the constant intercept $\beta_0$).

Topic 09 Estimated Time: 25 Mins

Interaction Terms & Residual Plots

1. Feature Synergy (Interaction Terms) 1 + 1 = 5 Effect

Sometimes two variables multiply each other's effectiveness. Example: Ad Spend ($x_1$) works okay on normal days, but during the Holiday Season ($x_2$), every ad dollar produces 10x more sales. The holiday multiplies the impact of advertising!

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \mathbf{\beta_3 (x_1 \cdot x_2)} + \epsilon$$

$\beta_3$ measures the extra multiplier bonus created when both $x_1$ and $x_2$ act together.

2. Error Health Checks (Residual Plots)

Residuals are your model's mistakes ($\text{Error} = \text{Actual} - \text{Predicted}$). A healthy model leaves behind pure random white noise. If you spot a shape or pattern in your error plot, your model missed crucial information!
