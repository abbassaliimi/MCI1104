Components of the Input

Core Concept: Before building a model, you must understand the anatomy of the data feeding into it. A standard dataset is a highly structured grid of information.

  • R Instances (The "Rows"): Individual, independent examples (records, data points, samples). E.g., In predicting house prices, one instance is a single house.
  • C Attributes (The "Columns"): Distinct properties, features, or characteristics. E.g., Number of bedrooms, square footage, neighborhood.
  • M The Matrix Form: In practice, you work with an N × M matrix, where N = instances and M = attributes.

Preparing the Input

Core Concept: "Garbage in, garbage out." Algorithms are strictly mathematical and sensitive to bad data. You must prepare raw input before any learning happens.

The 4 Key Pipelines

  • 1.Handle Missing Data: Impute (fill) or drop blanks.
  • 2.Encode Categories: Convert text to numbers (e.g., One-Hot).
  • 3.Handle Outliers: Identify extreme skewing anomalies.
  • 4.Normalize: Scale numbers to similar ranges (e.g., 0 to 1).

Practical Lab Walkthrough

Follow this step-by-step guide to understand how each Python command transforms raw input into clean, model-ready data:

1 Import Libraries

pandas handles tabular data matrices, and MinMaxScaler re-scales numeric columns.

2 Load & Inspect Dataset

pd.read_csv() loads the raw CSV into a DataFrame. .info() displays missing values and attribute data types.

3 Impute Missing Data

.fillna() replaces missing NaN values in the Salary column with the calculated column .mean().

4 Normalize Attributes

fit_transform() shrinks numeric ratio features (Distance) into a standard scale between 0.0 and 1.0.

5 Verify Transformed Data

.head() prints the top rows of the cleaned DataFrame to confirm all transformations.

# Step 1: Import required modules for data processing
import pandas as pd // Tabular manipulation
from sklearn.preprocessing import MinMaxScaler // Feature scaling
# Step 2: Load raw dataset and inspect attribute structure
df = pd.read_csv('housing_data.csv') // Load CSV matrix
print(df.info()) // Print column types & non-null counts
# Step 3: Handle missing values via Mean Imputation
mean_sal = df['Salary'].mean() // Calculate column average
df['Salary'].fillna(mean_sal, inplace=True) // Fill NaNs in-place
# Step 4: Scale numeric attributes to [0, 1] range
scaler = MinMaxScaler() // Instantiate scaler
df[['Distance']] = scaler.fit_transform(df[['Distance']]) // Apply scaling
# Step 5: Output preview of clean data matrix
df.head() // Output top 5 rows
