Translate visual exploratory data analysis (EDA) concepts into production Python code using Matplotlib and Seaborn:

1 Environment & Data Preparation

Import core visualization libraries, establish uniform figure styling via sns.set_theme(), and load target datasets for exploratory analysis.

2 Univariate EDA & Outliers
  • • kde=True: Overlays a continuous Kernel Density curve to evaluate shape, modality, and distribution skewness.
  • • sns.boxplot(): Identifies statistical anomalies sitting outside the $1.5 \times \text{IQR}$ threshold whiskers.
3 Multivariate Correlation Matrix
  • • annot=True: Displays explicit Pearson correlation values ($r$) directly within each matrix cell.
  • • cmap='coolwarm': Applies a diverging color scale to contrast inverse (blue) vs. direct (red) feature links.
# Step 1: Import modules & set rendering aesthetics
# Primary canvas plotting engine
import matplotlib.pyplot as plt
# High-level statistical graphics library
import seaborn as sns
# Apply global grid layout theme
sns.set_theme(style='darkgrid')
# Load sample dataset into DataFrame
df = sns.load_dataset('housing')
# Step 2: Plot distribution skewness & boxplot outliers side-by-side
# Initialize 1x2 grid subplot canvas
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
# Histogram + KDE density estimation on subplot 0
sns.histplot(df['price'], kde=True, ax=axes[0], color='#8b5cf6')
# Render boxplot to identify statistical outliers on subplot 1
sns.boxplot(x=df['price'], ax=axes[1], color='#10b981')
