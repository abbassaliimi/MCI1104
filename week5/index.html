Topic 01 Estimated Time: 30 Mins

Machine Learning Paradigm Mismatch

Core Concept: Standard supervised learning requires an input feature matrix ($X$) and an output target vector ($y$). However, a raw time series is simply a 1-dimensional array of values recorded over time (e.g., $[10, 15, 12, 18, 20]$).

The Problem

If your boss asks you to predict tomorrow's sales, and your data is just a single column of past sales, you don't have any independent "features" for a standard algorithm to learn from.

The Solution

Artificially create features out of the past. The core assumption is that history contains clues to the future (the data itself must become its own features).

Topic 02 Estimated Time: 30 Mins

Converting Time Series to Discrete Sequence Data

Core Concept: To satisfy machine learning algorithms, we use the Sliding Window Strategy (lag feature engineering) to transform sequential data into discrete, tabular matrix rows.

Creating "Lags"

Observation from a previous step. Today is $t$, yesterday is $t-1$, day before is $t-2$.

The Window Size

Past observations used as input features ($X$) to predict current target ($y$).

💡 Choosing Window Size: Look-back window requires experimentation. Daily temperature may need 3–7 lags, while 365 lags add unnecessary noise.

Topic 03 Estimated Time: 30 Mins

Time Series Forecasting and Baselines

Core Concept: Forecasting extrapolates the future from the past. Before building complex Neural Networks, you must establish a simple baseline model. If an advanced model cannot beat a basic baseline, it is useless!

Three Fundamental Baseline Strategies:
  • 1. Naïve Forecast: Predicts tomorrow will equal today ($\hat{y}_t = y_{t-1}$). Notoriously hard to beat in stock markets.
  • 2. Seasonal Naïve: Predicts tomorrow will equal the exact same season in the last cycle (e.g. this Saturday = last Saturday).
  • 3. Moving Average: Predicts future by taking the simple average of the last $N$ rolling periods.

Topic 04 Estimated Time: 30 Mins

Evaluating Forecast Accuracy

Core Concept: To know if your machine learning model beat the baseline, you need mathematical scoring metrics. You cannot just "eyeball" a line chart.

Mean Absolute Error (MAE)

$$\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$$

Interpretable for business ("Off by average of 5 units").

Root Mean Squared Error (RMSE)

$$\text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$

Squares errors to heavily penalize large mistakes.

Practical Lab Walkthrough

Act as a data engineer preparing chronological data for machine learning using Pandas and NumPy:

1 Lag Feature Creation

Use Pandas .shift() function to construct columns for $t-1$, $t-2$, and $t-3$. Watch the matrix take shape!

2 Data Cleanup (NaN Removal)

Shifting creates unfillable NaN gaps at the start of dataset. Safely drop them with .dropna().

3 Naïve Baseline MAE Evaluation

Calculate the baseline Mean Absolute Error (MAE) score that future ML models must beat.

# Step 1: Create Lag Features using Pandas .shift()
import pandas as pd
import numpy as np
df = pd.DataFrame({10, 15, 12, 18, 20, 25, 22]})
df[].shift(1)
df[].shift(2)
df[].shift(3)
# Step 2: Clean unfillable NaN gaps at dataset start
df_clean = df.dropna().reset_index(drop=True)
# Step 3: Compute Naïve Baseline MAE (Prediction = Lag t-1)
mae_baseline = np.mean(np.abs(df_clean[]))
print(f"Naïve Baseline MAE: {mae_baseline:.2f} units")
